> [!abstract] Exercise
> Code an application that takes the value of the switches through the GPIOs and puts it directly into the LEDs above the switches in the Genesys 2 board.

To code this application, please take a look into how GPIO works in Linux through sysfs.

## Expected Result and Deliverable

- Read switch values using Linux GPIO userspace interfaces.
- Mirror the state into the LED GPIOs.
- Build and run the application as done in Exercise 2.
- Save the source code and generated `.elf` file for delivery.
